# FRBench

The NYX benchmark, published here under the name FRBench: 235 contract projects
and 513 historical attack records.

- `contracts/`: original Solidity sources, compiler configuration, and artifacts.
- `attacks/`: original attack metadata and reference evidence.

Both directories preserve the archived benchmark files unchanged. Source:
[Nyx](https://github.com/Troublor/Nyx). This directory name does not change the
dataset's authorship or imply a new ground-truth collection.

The archived distribution's [license notice](UPSTREAM_LICENSE) is retained.
Individual contracts retain their own license and copyright notices.
