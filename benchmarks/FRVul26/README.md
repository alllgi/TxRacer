# FRVul26

A benchmark of 134 Ethereum event groups with unified sample identifiers.

- `samples/`: event groups and historical evidence.
- `contracts/`: shared contract sources and compilation artifacts.
- `annotations/`: compact contract labels and reference interactions.
- `provenance/`: original records and audit mappings.

See [EVALUATION.md](EVALUATION.md) for scoring and [SOURCES.md](SOURCES.md)
for attribution and licenses.
