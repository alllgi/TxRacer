# Benchmarks

| Dataset | Contents |
|---|---|
| [FRBench](FRBench/) | NYX benchmark: 235 contract projects and 513 attack records. |
| [FRVul26](FRVul26/) | 134 event groups with unified identifiers, contract sources, evidence, and labels. |

These datasets support smart-contract security research and evaluation.
See the [usage guide](../docs/usage.md) for analysis setup. Historical attack
records and annotations provide reference material for evaluation.

Third-party contracts and evidence retain their original copyright and license
notices. See each dataset's README for attribution. Follow [SECURITY.md](../SECURITY.md).
